🎨 Resume Builder - Complete Project Explanation

📖 Project Overview

Resume Builder is a full-stack web application that enables users to create, customize, and manage professional resumes with AI-powered enhancement features. The application combines a modern React frontend with a Node.js/Express backend, utilizing MongoDB for data persistence and OpenAI's API for intelligent resume content enhancement.

🛠️ Tech Stack

Frontend Technologies

  • React 19.1.1 - UI Framework
  • Redux Toolkit 2.12.0 - State Management
  • React Router DOM 7.9.4 - Routing
  • Axios 1.18.1 - HTTP Client
  • Tailwind CSS 4.1.14 - Styling
  • Vite 7.1.7 - Build Tool
  • Lucide React - Icons
  • React Hot Toast - Notifications

Backend Technologies

  • Node.js - Runtime
  • Express 5.2.1 - Web Framework
  • MongoDB - Database
  • Mongoose 9.7.2 - ODM
  • JWT - Authentication
  • Bcrypt - Password Hashing
  • Multer - File Upload
  • OpenAI - AI Integration
  • ImageKit - Image CDN

🏗️ Project Architecture

Architecture Type: MVC (Model-View-Controller) with React for the View layer

The application follows a client-server architecture:

Frontend (React) ├── Pages (Home, Dashboard, Builder, Preview) ├── Components (Forms, Preview, Templates) ├── Redux Store (Auth State) └── Axios API Client (HTTP Requests) ↓ HTTP/HTTPS Backend (Express + Node.js) ├── Routes (User, Resume, AI) ├── Controllers (Business Logic) ├── Middlewares (Auth, File Upload) ├── Models (User, Resume) └── Services (AI, ImageKit) ↓ Database MongoDB ├── Users Collection └── Resumes Collection

🖥️ Backend Architecture

Server Setup (Express)

Main File: server.js
Port: 3000 (configurable via .env)
Database: MongoDB connection on startup
Middleware: CORS enabled, JSON parsing enabled

Routes Structure

Module Base Path Endpoints
User Routes /api/users register, login, data, resumes
Resume Routes /api/resumes create, update, delete, get, public
AI Routes /api/ai enhance-pro-sum, enhance-pro-desc, upload-resume

Controllers & Business Logic

Controllers handle:

  • User Controller: Registration, login, profile data, resume list
  • Resume Controller: CRUD operations for resumes
  • AI Controller: OpenAI API calls for enhancement and PDF parsing
  • Multer Controller: File upload handling

📊 Data Models

User Model

User { _id: ObjectId, name: String (required), email: String (required, unique), password: String (hashed), createdAt: Date, updatedAt: Date }

Resume Model

Resume { _id: ObjectId, userId: ObjectId → User, title: String, public: Boolean, template: String, accent_color: String, professional_summary: String, skills: [String], personal_info: { image: String (ImageKit URL), full_name: String, profession: String, email: String, phone: String, location: String, linkedin: String, website: String }, experience: [{ company: String, position: String, start_date: String, end_date: String, description: String, is_current: Boolean }], education: [{ institution: String, degree: String, field: String, graduation_date: String, gpa: String }], project: [{ name: String, type: String, description: String }], createdAt: Date, updatedAt: Date }

🔌 API Endpoints

User Endpoints

Method Endpoint Auth Description
POST /api/users/register ❌ Register new user
POST /api/users/login ❌ Login existing user
GET /api/users/data ✅ Get current user data
GET /api/users/resumes ✅ Get all user's resumes

Resume Endpoints

Method Endpoint Auth Description
POST /api/resumes/create ✅ Create new resume
PUT /api/resumes/update ✅ Update resume (with image)
DELETE /api/resumes/delete/:resumeId ✅ Delete resume
GET /api/resumes/get/:resumeId ✅ Get resume (private)
GET /api/resumes/public/:resumeId ❌ Get resume (public)

AI Endpoints

Method Endpoint Auth Description
POST /api/ai/enhance-pro-sum ✅ Enhance professional summary
POST /api/ai/enhance-pro-desc ✅ Enhance job description
POST /api/ai/upload-resume ✅ Upload & parse resume PDF

🔄 Complete User Flows

Flow 1: Sign Up & Create First Resume

1. User visits app 2. Clicks "Get Started" or "Sign Up" 3. Fill registration form 4. POST /api/users/register 5. Server creates user (password hashed) 6. JWT token returned and stored 7. Redux state updated 8. Navigate to Dashboard 9. Click "Create New Resume" 10. POST /api/resumes/create 11. Navigate to builder

Flow 2: AI Enhancement

1. User enters professional summary 2. Clicks "Enhance with AI" 3. POST /api/ai/enhance-pro-sum 4. Backend calls OpenAI API 5. Returns enhanced text (2-3 sentences) 6. Text appears in input field 7. User can edit and save

Flow 3: Upload Existing Resume

1. User selects PDF file 2. react-pdftotext extracts text 3. POST /api/ai/upload-resume 4. OpenAI parses structured data 5. Server creates resume with data 6. Returns resumeId 7. Navigate to builder

Flow 4: Share & Publish

1. User in Resume Builder 2. Toggle "Make Public" 3. PUT /api/resumes/update {public: true} 4. Click "Share" 5. Get shareable link: /view/:resumeId 6. Anyone can view without login

🔒 Authentication & Security

Password Security

  • Passwords hashed using bcrypt (10 salt rounds)
  • Never stored in plaintext
  • Never returned in API responses
  • Comparison using comparePassword() method

JWT Authentication

  • 12-day token expiration
  • Signed with server secret
  • Verified on every protected request
  • UserId extracted from token and passed to controllers

Protected Endpoints

  • User data: Requires valid JWT
  • Resume operations: Requires valid JWT
  • AI endpoints: Requires valid JWT
  • Public resume viewing: No auth (only if marked public)

Authorization

  • Server validates userId from token matches request
  • Users can only access their own resumes
  • Cannot modify other user's data
